Driftnote’s feedback board runs on Lort. Why not yours?

Lort is a free, open-source feedback board, roadmap and changelog that you host on your own server. People stick dots on what they want while you build it, and they find out once it’s done.

From suggestion to shipped

Every request moves along the same line. When it reaches Completed, everyone who asked for it or stuck a dot on it gets an email.

Run it on your own server

One Docker container holds the board, the database, HTTPS and email.

Point a subdomain at your server

Any VPS works. Add an A record like this at your DNS provider:

feedback.yoursite.com A 203.0.113.24
Clone it and run the setup script

The script checks for Docker, then walks you through setup and builds the image.

git clone https://github.com/hacker4ofakind/lort && cd lort ./setup.sh
Start it

The script prints this exact line for your server. Run it and your board is live.

docker run -d --name lort --restart unless-stopped \ -p 80:80 -p 443:443 -v lort_data:/data --env-file .env lort

Your agent can run the board

Every Lort comes with an MCP server. Ask Claude Code or Cursor to triage new requests, move things on the roadmap or write the changelog. Webhooks tell Discord, Slack or your own code what happened.

claude mcp add --transport http lort \ https://feedback.yoursite.com/mcp \ --header "Authorization: Bearer lort_…"

“Move every bug with more than 20 votes to Planned and draft a changelog for what shipped this week.”

Say it instead of typing it

Turn on voice dictation and Whisper runs on your server, so nothing leaves it. Screenshots go in the same box.

Mark it done, and everyone hears

Completing a request emails everyone who voted, after a minute in which you can still undo it. Changelog posts can complete the requests they mention, now or on a schedule.
